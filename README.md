# Suweal

[![Package Version](https://img.shields.io/hexpm/v/suweal)](https://hex.pm/packages/suweal)
[![Hex Docs](https://img.shields.io/badge/hex-docs-ffaff3)](https://hexdocs.pm/suweal/)

Suweal is a library for interacting with [SurrealDB](https://surrealdb.com/). This library is currently unpublished with no currently plans to publish it.

> ⚠️ This library is highly experimental and subject to change.

```toml
[dependencies]
suweal = ">= 0.3.1 and < 1.0.0"
```
```gleam
import suweal

pub fn main() -> Nil {}
```
